# QuantumShield API Contract

This document defines the API endpoints used for communication between the Frontend (React), the Go Backend, and the Layer 3 Quantum Computing Engine (Python).

## 1. POST `/api/optimize`
**Description:** Triggers the Layer 3 Quantum Resource Allocation Engine. The Go backend executes the `08_quantum_allocation.py` script synchronously.

**Request:**
- **Method:** `POST`
- **Headers:** None required.
- **Body:** None required.

**Response:**
- **Status:** `200 OK` on success, `500 Internal Server Error` on failure.
- **Body:** Plain text message `"Quantum allocation executed"` if successful.

---

## 2. GET `/api/allocation`
**Description:** Retrieves the latest allocation results generated by the Layer 3 Engine. The backend reads this data from `artifacts/allocation_output.json`.

**Request:**
- **Method:** `GET`

**Response:**
- **Status:** `200 OK`
- **Content-Type:** `application/json`

**Response Payload Example:**
```json
{
  "quantum_allocation": {
    "solver": "dimod.ExactSolver",
    "qubo_variables": 1,
    "timestamp": "2026-07-08T03:54:36Z",
    "alert_region": "Ho Chi Minh",
    "alert_probability": 95
  },
  "resources_available": {
    "staff_teams": 5,
    "beds": 53,
    "kits": 808
  },
  "allocation_result": {
    "covered_regions": [
      {
        "region": "Ho Chi Minh",
        "lat": 10.7626,
        "lng": 106.6601,
        "riskScore": 100,
        "riskScoreNormalized": 1.0
      }
    ],
    "waiting_regions": [],
    "staff_teams_deployed": 1,
    "staff_teams_budget": 5,
    "total_risk_score_covered": 1.0,
    "coverage_percent": 100.0
  },
  "summary": "Deploying 1 of 5 available staff teams to highest-risk regions."
}
```

### Key Fields:
- `allocation_result.covered_regions`: Array of objects representing regions that received resource allocations. Each object contains geographical coordinates and the risk score.
- `allocation_result.waiting_regions`: Array of objects representing regions that did not receive resources due to budget limits.
- `allocation_result.coverage_percent`: The percentage rate of risk covered by the quantum algorithm.
- `allocation_result.staff_teams_deployed`: The optimal number of medical staff teams deployed.

# QuantumShield - Data Integration Contract

## Introduction
This document defines the standard structure of the data contracts exchanged between components in the QuantumShield ecosystem:
1. `data.json`: Created by the AI Prediction (Python) team to store outbreak forecasts and risk hotspot details. It is read by the Backend (Go) service to stream live telemetry.
2. `allocation_output.json`: Generated by the Quantum Resource Allocation engine (`08_quantum_allocation.py`) to store optimization results. It is read by the Backend (Go) and displayed in the frontend dashboard.

---

## 1. Outbreak Telemetry (`data.json`)
This file is outputted to the `artifacts/` folder. It provides current alert levels, forecasting details, and threat hotspots.

### JSON Structure
```json
{
  "alert": {
    "active": true,
    "region": "Ho Chi Minh",
    "probability": 95,
    "message": "Dengue risk is Critical Risk based on forecasting models."
  },
  "forecast": {
    "beds": 53,
    "kits": 808,
    "staffTeams": 5
  },
  "hotspots": [
    {
      "lat": 10.7626,
      "lng": 106.6601,
      "region": "Ho Chi Minh",
      "riskScore": 100
    },
    {
      "lat": 10.8,
      "lng": 106.7,
      "region": "Binh Duong",
      "riskScore": 72
    }
  ]
}
```

### Schema Details:
*   **alert** (Object):
    *   `active` (boolean): Outbreak alert status.
    *   `region` (string): Primary affected area.
    *   `probability` (number): Predicted outbreak probability (%).
    *   `message` (string): Detailed alert description.
*   **forecast** (Object):
    *   `beds` (number): Forecasted additional hospital beds required.
    *   `kits` (number): Forecasted diagnostic testing kits required.
    *   `staffTeams` (number): Mobile medical teams required.
*   **hotspots** (Array of Objects): List of threat regions.
    *   `lat` (number): Latitude.
    *   `lng` (number): Longitude.
    *   `region` (string): Name of the province/region (standardized to unaccented characters).
    *   `riskScore` (number): Computed risk index (0-100).

## 2. Resource Allocation (`allocation_output.json`)
This file is outputted to the `artifacts/` folder after running the quantum QUBO allocation solver.

### JSON Structure
```json
{
  "allocation_result": {
    "covered_regions": [
      {
        "region": "Ho Chi Minh"
      },
      {
        "region": "Binh Duong"
      }
    ],
    "waiting_regions": [
      {
        "region": "Dong Nai"
      }
    ],
    "staff_teams_deployed": 5,
    "coverage_percent": 66.7
  }
}
```

### Schema Details:
*   **allocation_result** (Object):
    *   `covered_regions` (Array of Objects): Regions successfully assigned medical resources.
        *   `region` (string): Standardized unaccented region name.
    *   `waiting_regions` (Array of Objects): Hotspot regions currently waiting for resources.
        *   `region` (string): Standardized unaccented region name.
    *   `staff_teams_deployed` (number): Number of medical teams deployed by the optimizer.
    *   `coverage_percent` (number): Ratio of covered regions to total hotspots (%).

## 3. UI Representation: How Optimization Results are Displayed
When the Quantum Resource Allocation is executed, the Frontend Dashboard reacts dynamically to the changes in `allocation_output.json` through the following visual updates:

### 3.1. Main Map (Geospatial Risk Intelligence)
The 63-province map of Vietnam changes color based on the allocation result:
*   **Covered/Allocated Regions (`covered_regions`):** 
    *   The province polygon is colored **Emerald Green** (`#10b981`) with a glowing green border (`#34d399`) and an elevated opacity (`0.85`), signaling that resources have been safely deployed.
*   **Threat Hotspots Waiting (`waiting_regions`):** 
    *   The province polygon is colored **Red** (`#ef4444`) with red circle markers flashing over its centroid, signaling that it is still a pending threat waiting for medical team allocation.
*   **Safe/Unmonitored Regions:**
    *   Colored Slate Gray (`#cbd5e1`) with lower opacity (`0.4`).

### 3.2. AI Analytics Drawer (Locality Details)
When a user clicks on any province to open the right-side sliding drawer:
*   An additional **Quantum Status** row appears at the top.
*   If the region is covered, it displays a bright green badge: `DEPLOYED`.
*   If the region is a hotspot waiting for allocation, it displays a gray badge: `PENDING`.

### 3.3. Dashboard KPI Cards
*   **Allocation Rate Card:** The percentage rate dynamically transitions to match `coverage_percent` (e.g. `62.5%`).
*   **Medical Workforce Card:** The status transitions to **OPTIMIZED** with a green badge showing the count of teams deployed (e.g. `Deployed 5 Teams` based on `staff_teams_deployed`).

---

## Standardization Note
> [!IMPORTANT]
> To avoid string mismatches between layers (Python AI ➔ Go Backend ➔ GeoJSON Frontend), all region/province names must be standardized to **unaccented English text** (e.g. `Ho Chi Minh`, `Binh Duong`, `Long An`, `Ba Ria-Vung Tau`).
